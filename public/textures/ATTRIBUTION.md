# 行星貼圖授權

本資料夾的 `mercury.jpg`、`venus_surface.jpg`、`venus_atmosphere.jpg`、`earth_daymap.jpg`、`earth_nightmap.jpg`、`earth_clouds.jpg`、`mars.jpg`、`jupiter.jpg`、`saturn.jpg`、`saturn_ring.png`、`uranus.jpg`、`neptune.jpg` 取自 [Solar System Scope Textures](https://www.solarsystemscope.com/textures/)，作者 Solar System Scope / INOVE，依 [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/) 授權使用。檔案重新命名，未修改圖像內容。

`earth_nightmap_4k.jpg` 與 `earth_clouds_4k.jpg` 取自同一素材集的較高解析度版本，縮放為 4096×2048，依相同 CC BY 4.0 條款使用。

`earth_daymap_4k.jpg` 取自 [NASA Earth Observatory Blue Marble: Next Generation 2004 年 2 月全球底圖](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-map/)，原始 5400×2700 JPEG 縮放為 4096×2048。NASA 影像使用遵循 [NASA Media Usage Guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/)；此處標示來源，不暗示 NASA 認可本站。

Solar System Scope 說明其貼圖以 NASA 影像與高程資料為基礎，部分尚未測繪區域使用補繪地形，色彩亦經視覺調整。因此網站將其標示為科學資料啟發的視覺貼圖，不宣稱每一像素均為直接觀測。

太陽、星系、星座、星雲、黑洞與幻想星球使用本站程式生成的幾何、粒子和 shader。黑洞的透鏡效果是視覺近似。
