# ASTRAEON｜專案願景

## 現況與設計前提

- 2026-09-19 檢查指定目錄：空資料夾、無 Git metadata、無可重用程式碼或資產。原訊息的附圖未在工作區出現；使用者後續提供的 CodePen 連結已作為視覺參考並檢視其畫面與切換互動。若另有附圖，收到後再核對構圖、字體、色彩、留白及動效語彙。
- 定位：一座可探索、可學習、可收藏的「宇宙觀測台」。科學天體清楚標示資料來源與近似程度；原創幻想天體有明顯的 fiction 標籤。
- 體驗節奏：宇宙總覽 → 星系 → 恆星系 → 天體 → 地表。各尺度都是獨立場景，不以單一線性比例假裝可同時呈現整個宇宙。
- 視覺主軸：參考 [Celestial Transmutation](https://codepen.io/VoXelo/pen/yygKOVy) 的近黑藍背景、置中巨大發光天體、左側大字標題、頂端細小狀態與底部膠囊選單；以青藍、紫及隨天體改變的重點色建立氛圍。資訊面板屬於觀測儀器，不能遮住主體。參考站的概念星球切換只作構圖與動效參考，不取代 ASTRAEON 的真實尺度場景。

## 成功定義

首訪者 30 秒內能選到太陽系並聚焦地球；可從地球返回宇宙總覽而不迷失。知識資料、視覺特效和互動行為各有獨立配置，可在不改 shader 的情況下新增一顆資料完整的天體。

```ts
type ExperiencePromise = {
  entry: 'universe';
  scalePath: ['universe', 'galaxy', 'stellar-system', 'body', 'surface'];
  pillars: ('wonder' | 'orientation' | 'credibility' | 'agency')[];
  provenance: 'observed' | 'derived' | 'artistic' | 'fictional';
};
```

## 階段任務

P0 確認參考圖與內容授權、完成可點擊資訊架構；P1 做太陽系與地球垂直切片；P2 擴展銀河、仙女座、星座、星雲；P3 做黑洞與幻想星球；P4 完成導覽、可及性及行動裝置修整。詳見 IMPLEMENTATION_ROADMAP。

## 驗收標準與效能預算

- 視覺驗收：地球、土星、銀河、黑洞四張對照畫面能一眼辨識為不同幾何、材質及光照技術；完整場景可自由移動視角。
- 內容驗收：每則真實天體介紹附來源與最後審核日期；虛構內容不得進入科學篩選結果。
- 目標設備：桌面 1080p 中階 GPU 60 fps 中位數、30 fps 的 1% low；手機 390×844 中階裝置 30 fps 中位數。首個可互動畫面 ≤4 秒（桌面快速網路）／≤8 秒（手機 4G 測試環境）；預算與量測條件見 PERFORMANCE_PLAN。

## 風險與取捨

最大風險是範圍過廣、素材授權不明、跨尺度精度，以及手機 GPU 容量。先完成可反覆使用的場景與資料契約，再擴充內容；超出效能預算時降低粒子密度與後處理，不刪除辨識天體所需的核心幾何。
