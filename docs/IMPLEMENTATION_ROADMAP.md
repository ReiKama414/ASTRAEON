## 執行原則

原始階段僅規劃；使用者於規劃完成後指示繼續，現已啟動可運作的探索切片。先建立可測的地球與太陽系垂直切片，再擴充內容。每一階段需通過功能、畫質、效能、可及性四道驗收；未過關先修復，不把瓶頸推到下一階段。估時是相對規劃而非交付承諾。

截至 2026-09-20：P1 的 UI、行星、太陽系總覽與主要互動已有原型；P2/P3 的星系、星座、星雲、黑洞與幻想星球有可探索的視覺切片。尚未完成星曆、真實地形、完整六模式相機、KTX2 和實機效能門檻驗證。可執行方式與已知限制見根目錄 README。

type PhaseGate = {

## P0｜設計與技術驗證（約 1–2 週）

凍結參考畫面的可借鑑元素；定義路由、資料 schema、授權台帳、目標測試設備。做一次地球大氣、土星環、星系旋臂、黑洞盤的技術小樣與 GPU 記錄，只用來驗證風險。驗收：四類效果都有明確方案、來源與降級路徑；確認 60/30 fps 基準是否可行。風險：參考圖與素材授權滯後；若未確定，先用自製測試素材。

## P1｜可使用的太陽系切片（約 3–5 週）

建 React/Vite/R3F 架構、Zustand slices、場景載入與恢復；完成太陽、八行星、地球近景、Orbit/Focus、搜尋、收藏、百科、時間與全螢幕。驗收：地球 3 次點擊可達、20 次場景往返無洩漏；桌面 60 fps 中位數、手機 30 fps；首互動 ≤4/8 秒。風險：地球多層材質與體積大氣過重，需分 tier。

## P2｜宇宙尺度與天球（約 3–4 週）

完成宇宙總覽、銀河／仙女座旋臂、獵戶座與至少兩組其他星座、兩類星雲；補 Follow、分類導覽、來源註記。驗收：跨尺度返回正確、星座觀測方向標記清楚、星雲是真正多層 3D 粒子／密度結構；沿用 P1 效能門檻。風險：大尺度精度與粒子 overdraw。

## P3｜高階奇觀與導覽（約 3–4 週）

完成黑洞吸積盤與透鏡近似、原創幻想星球、Free Fly、Surface View、Cinematic Tour。驗收：黑洞效果有可視的背景扭曲且標示模擬；各幻想星球材質和幾何差異明確；Tour 可隨時中斷；沿用效能門檻。風險：自訂 shader 可攜性與地表內容成本。

## P4｜交付修整（約 1–2 週）

做裝置矩陣、鍵盤與螢幕閱讀器、reduced motion、WebGL context restore、資產授權審核及長時間運行。驗收：無 WebGL 時百科／搜尋／收藏可用；失去 context 後 10 秒內出現恢復路徑；所有出貨素材有 license record；長測無持續記憶體成長。

## 共同預算與風險決策

桌面 1080p 60 fps 中位數／GPU ≤12 ms／≤300 draw calls／≤512 MB GPU textures；手機 390×844 30 fps／GPU ≤25 ms／≤150 draw calls／≤192 MB。若 P0 實機證明不達標，先調整 DPR、LOD、粒子與 pass，然後重新核定內容密度。可重用程式碼盤點結果：指定目錄為空；若之後導入其他來源，先審核授權、API 相容與效能再決定保留。
